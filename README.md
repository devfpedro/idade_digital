# Idade Digital

**Inclusão Digital para a Pessoa Idosa: Promovendo Autonomia e Cidadania por Meio da Tecnologia**[cite: 1, 2]

Esta plataforma web foi desenvolvida para promover o ensino tecnológico e o letramento digital de pessoas com mais de 60 anos. O objetivo é capacitar os usuários no manuseio de computadores e smartphones, permitindo que utilizem a tecnologia no dia a dia de forma autônoma e segura, além de conscientizá-los sobre a prevenção contra fraudes virtuais[cite: 1, 2].

## 🛠️ Tecnologias Utilizadas

*   **Front-end:** React.js (Vite)
*   **Back-end:** Python (Flask)
*   **Banco de Dados:** PostgreSQL

## 📋 Pré-requisitos

Antes de iniciar, certifique-se de ter as seguintes ferramentas instaladas em sua máquina:
*   [Git](https://git-scm.com/)
*   [Node.js](https://nodejs.org/) (recomendado versão LTS)
*   [Python 3](https://www.python.org/)
*   [PostgreSQL](https://www.postgresql.org/)

## 🚀 Como executar o projeto localmente

### 1. Clonar o repositório

Primeiro, clone o repositório para a sua máquina e acesse a pasta raiz do projeto:

```bash
git clone [https://github.com/devfpedro/idade_digital.git](https://github.com/devfpedro/idade_digital.git)
cd idade_digital
```

### 2. Configurando o Front-end

Acesse o diretório do front-end

```bash
cd frontend
```

Instale as dependências do projeto

```bash
npm install
```

Inicie o servidor de desenvolvimento

```bash
npm run dev
```

### 3. Configurando o Back-end

A partir da raiz do projeto, acesse o diretório do back-end

```bash
cd backend
```

Crie o ambiente virtual (recomendado nomear como 'venv')

```bash
python -m venv venv
```

## 4. Ativando o ambiente virtual:

No Windows:

```bash
venv\Scripts\activate
```

No Linux/Mac

```bash
source venv/bin/activate
```
